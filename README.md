# Forest Adventure

A simple text-based choose-your-own-adventure game built in Python.

## Story
You wake up in a dark forest with no memory of how you got there. 
Do you head toward the river, or brave the cave in search of a way out?

## How to run
python story.py

## What I learned
- Functions
- Conditionals (if/else)
- Loops (while)
